# A61 Benoni Defense <br> 1. d4 Nf6 2. c4 c5 3. d5 e6 4. Nc3 exd5 5. cxd5 d6 6. Nf3 g6 #

Spun off from [A60_Modern_Benoni.md](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A60_Modern_Benoni.md), where **6. Nf3** used to live as a candidate bullet. Live-confirmed via the Lichess explorer's own `opening` field, cross-checked against [chessopenings.com's ECO reference](https://chessopenings.com/eco/A61): the same class of "wrong root code" split already applied elsewhere in this repo.
