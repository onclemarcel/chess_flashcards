# A58 Benko Gambit Accepted: Fully Accepted Variation <br> 1. d4 Nf6 2. c4 c5 3. d5 b5 4. cxb5 a6 5. bxa6 #

Spun off from [A57_Benko_Gambit.md](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A57_Benko_Gambit.md), where **5. bxa6** used to live as a candidate bullet. Live-confirmed via the Lichess explorer's own `opening` field, cross-checked against [chessopenings.com's ECO reference](https://chessopenings.com/eco/A58): the same class of "wrong root code" split already applied elsewhere in this repo. White takes the second pawn, betting the resulting queenside structure genuinely favours White despite Black's coming piece activity down the open a- and b-files.
