# A54 Old Indian Defense: Ukrainian Variation <br> 1. d4 Nf6 2. c4 d6 3. Nc3 e5 #

Spun off from [A53_Old_Indian_Defense.md](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A53_Old_Indian_Defense.md), where **3... e5** used to live as a candidate bullet. Live-confirmed via the Lichess explorer's own `opening` field, cross-checked against [chessopenings.com's ECO reference](https://chessopenings.com/eco/A54): the same class of "wrong root code" split already applied elsewhere in this repo. Black strikes the centre immediately rather than developing the queen's knight first — the move that walks into a queen trade if played too early (4. dxe5 dxe5 5. Qxd8+), which is exactly why 3... Nbd7 first is masters' more common route into similar structures (see [A53](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A53_Old_Indian_Defense.md#_Nbd7_)).
