# A86 Dutch Defense: Fianchetto Variation <br> 1. d4 f5 2. c4 Nf6 3. g3 #

Spun off from [A84_Dutch_c4_Systems.md](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A84_Dutch_c4_Systems.md), where **3. g3** used to live as a candidate bullet. Live-confirmed via the Lichess explorer's own `opening` field, cross-checked against [chessopenings.com's ECO reference](https://chessopenings.com/eco/A86): the same class of "wrong root code" split already applied elsewhere in this repo — `eco.md`'s own entry just reads "With c4 & g3", another real name divergence from Lichess's own *Fianchetto Variation* tag. White commits to both flank pawns before Black's own structure is set.
