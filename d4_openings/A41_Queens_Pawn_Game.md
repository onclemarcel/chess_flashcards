# A41 Queen's Pawn Game <br> 1. d4 d6 #

Spun off from [A40's own root stats table](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A40_QPG.md#_initial_move_), where **d6** sat at a real 4.6% online / 2.8% masters share with no candidate bullet or card pointing to it — the exact position independently spotted as missing during this repo's own Phase D ECO audit (this repo had already built [`A53_Old_Indian_Defense.md`](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A53_Old_Indian_Defense.md), 1. d4 Nf6 2. c4 d6, but never the plain 1. d4 d6 shown here — a different position reached one move order earlier, and the specific one this whole line of enquiry started from).

**A41 is one of Lichess's most overloaded codes**: it carries at least seven genuinely distinct names depending on the exact continuation (Queen's Pawn Game, Modern Defense, Old Indian Defense, Rat Defense, Robatsch Defense, Wade Defense, Zukertort Opening), which is exactly why a naive search missed it in the first place. The bare position below is tagged plain **"Queen's Pawn Game"** — the **Old Indian Defense** name only attaches once White specifically replies **2. c4** (below), and it is *not* White's most common try here.
