Spun off from [A58_Benko_Gambit_Fully_Accepted.md](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A58_Benko_Gambit_Fully_Accepted.md), where **8. e4** used to live as a candidate bullet (via the different move order 7. Live-confirmed via the Lichess explorer's own `opening` field, cross-checked against [chessopenings.com's ECO reference](https://chessopenings.com/eco/A59): the same class of "wrong root code" split already applied elsewhere in this repo — `eco.md`'s own name for this exact position is just "7. e4", while Lichess live-tags the whole code the *Yugoslav*. White grabs the maximum centre immediately, before Black gets to fianchetto the king's bishop.
