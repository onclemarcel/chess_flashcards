# A55 Old Indian Defense: Normal Variation <br> 1. d4 Nf6 2. c4 d6 3. Nc3 Nbd7 4. e4 e5 5. Nf3 #

Spun off from [A53_Old_Indian_Defense.md](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A53_Old_Indian_Defense.md), where this tabiya used to be built as if it stayed A53. Live-confirmed via the Lichess explorer's own `opening` field, cross-checked against [chessopenings.com's ECO reference](https://chessopenings.com/eco/A55): the same class of "wrong root code" split already applied elsewhere in this repo — and a genuine transposition curiosity: this exact position is *also* reachable via [`A54_Old_Indian_Ukrainian_Variation.md`](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A54_Old_Indian_Ukrainian_Variation.md)'s own 4. Nf3 line (3... e5 4. Nf3 Nbd7 5. e4) — the identical final FEN reached by swapping the order of Black's Nbd7/e5 and White's e4/Nf3. Masters' actual main line into the true Old Indian tabiya: **4. e4** claims the centre while the knight already guards e5, then **5. Nf3** develops naturally once Black has committed to the central break.
