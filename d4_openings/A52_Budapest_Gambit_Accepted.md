# A52 Indian Defense: Budapest Gambit Accepted, Main Line <br> 1. d4 Nf6 2. c4 e5 3. dxe5 Ng4 #

Spun off from [A51_Budapest_Gambit_Declined.md](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/A51_Budapest_Gambit_Declined.md), where this position used to be built out as if it stayed A51. Live-confirmed via the Lichess explorer's own `opening` field, cross-checked against [chessopenings.com's ECO reference](https://chessopenings.com/eco/A52): the same class of "wrong root code" split already applied elsewhere in this repo. Masters' clear main try after 3. dxe5 (87.0%) — the real Budapest Gambit, immediately hopping the knight back to attack the e5 pawn and eye f2.

> [!NOTE]
> **4. e4!?**, the *Alekhine Variation* (+0.5, mention-only), grabs the maximum centre instead of directly defending the e5 pawn — almost always met by **4... Nxe5** (97.0% masters), regaining the pawn at once. Deeper still, **5. f4 Nec6** (the *Abonyi Variation*, +0.5, mention-only) retreats the knight again to keep it safe from a further tempo-gaining advance; **4... d6**, live-tagged the *Tartakower Defense* (`eco.md` calls it the *Balogh Gambit* — another real name divergence between the two sources) instead keeps the central tension a move longer (+0.8, mention-only, essentially untested at master level).
