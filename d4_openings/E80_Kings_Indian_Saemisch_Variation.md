# E80 King's Indian Defence: Sämisch Variation <br> 1. d4 Nf6 2. c4 g6 3. Nc3 Bg7 4. e4 d6 5. f3 #

Continues from [E70's own "4... d6" node](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/E70_Kings_Indian.md#_d6_), and from [E70's own "5. f3" note](https://github.com/onclemarcel/chess_flashcards/blob/main/d4_openings/E70_Kings_Indian.md#_f3_), which correctly identified this move as the Sämisch Variation and flagged it as a backlog item — this is that backlog, built out in full. **5. f3** (18.9% masters at E70's own fork) is White's most committal try against the King's Indian: instead of developing normally, White prepares an immediate Be3/Qd2/O-O-O plan and a full-scale kingside pawn storm, at the cost of some time and a slight structural loosening around the king. `eco.md` packs this single ECO code around one bare entry — the root position itself — but the Sämisch Variation is the longest unbroken chain of ECO codes in the whole King's Indian complex: 14 named entries run E80 through E89 without a single gap, all sharing this one 5. f3 trunk.
