Live-confirmed via the Lichess explorer's own `opening` field, cross-checked against [chessopenings.com's ECO reference](https://chessopenings.com/eco/A83): the same class of "wrong root code" split already applied elsewhere in this repo — `eco.md` calls this exact position "Staunton's line", but Lichess carries the same generic *Staunton Gambit* tag here as at A82's own root.
