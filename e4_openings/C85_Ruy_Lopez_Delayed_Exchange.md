# C85 Ruy Lopez: Closed, Delayed Exchange <br> 1. e4 e5 2. Nf3 Nc6 3. Bb5 a6 4. Ba4 Nf6 5. O-O Be7 6. Bxc6 #

Spun off from [C84's own "6. Bxc6" candidate bullet](https://github.com/onclemarcel/chess_flashcards/blob/main/e4_openings/C84_Ruy_Lopez_Morphy_Closed.md#_initial_move_) — a real minority try there (4.0% masters), already live-tagged its own code. `eco.md` calls this the *Exchange Variation Doubly, Deferred*; the live explorer tags it more simply the ***Delayed Exchange***. Trades the bishop for the knight two full tempi later than C68's own Exchange Variation, after Black has already committed both ... a6 and ... Nf6/... Be7.
